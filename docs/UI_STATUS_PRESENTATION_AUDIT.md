# Redis 界面状态信息审查与调整方案

日期：2026-10-18。审查代码基线：`main / ddbd7f1`。本轮交付为审查、实施顺序和独立 HTML 样例；**尚未修改正式组件、安装包或 Redis 行为**。

## 主要判断

当前部分信息已经具备按钮和状态数据，但显示层又逐行解释了一遍。自动刷新是典型例子：按钮、间隔选择、启停状态、成功时间分散呈现，样式还把后两项强制各占一整行。正常浏览时，文字及状态条不断挤占表格和预览高度。

建议使用统一规则：**操作由控件表达，正常状态由控件外观和短数值表达；影响数据理解的状态就地保留短标签，错误说明只在发生时出现。** 字段名称、实际数据、必要表单标签继续显示。

范围不包含更换青紫橘图标配色、重做左右分栏、改变选行联动、增加写功能或放宽读取限制。正式实施应直接使用现有状态，避免新增一套计时/读取逻辑。

## 自动刷新控件的具体方案

推荐控件示意：`[ 自动刷新图标开关 ][ 5s ▾ ]`。下拉只设间隔，左侧按钮只切换启停；手动刷新保留单独的刷新箭头。整个区域正常时不因开关而增加高度。

| 现有状态 | 建议外观 | 可访问名称 / 下一步 |
| --- | --- | --- |
| 未开启，ready | 中性边框、自动刷新图标、5s | “自动刷新已关闭，间隔5秒；点击开启”。 |
| enabled，等待 | 按下态/青色强调、固定图标、5s | “自动刷新已开启，间隔5秒；点击停止”。不常驻“等待下一轮”。 |
| enabled，busy | 同一控件，读取图标旋转；取消可用 | “正在自动读取；停止自动刷新”。减少动态效果设置下用静态忙态。 |
| hidden导致停止 | 中性控件加暂停形状 | “因页面隐藏已停止”；重新可见后按现有ready条件显式开启，不自动重启。 |
| failed且尚未恢复读取 | 自动刷新保持停止；异常标记，实际错误靠近结果 | 先手动读取并恢复ready，之后才能重新开启。不能做一个始终可点的“恢复”按钮绕过前置条件。 |
| cancelled | 停止态；保留当前读取取消后的必要提示 | 沿用现有取消和手动重读规则。 |

`AutoRefreshClock` 已有 `enabled/busy/ready/intervalMs/sampledAt/reason`，足以驱动上表。**不增加假倒计时、额外轮询或另一套自动刷新状态机。** `reason` 表示停止原因：后续手动读取成功时，历史失败原因不应再被文案描述成“当前仍读取失败”；展示时结合ready与当前结果判断。

上次成功表示当前reader最近成功采样，可能来自手动读或后续页。时钟入口称“最近读取”，不误称“最近自动刷新成功”。原始时间与具体停止原因可在这个入口展开，不再占常驻行。

## 计数和部分数据的呈现规则

- 未筛选且从起点完整浏览的列表，可显示 `760 / 760` 或 `8 / 8`，无障碍名称明确“已加载 / 总数”。
- MATCH场景显示“12匹配 · 总236”或“已加载12”，并保留筛选条件；不显示 `12/236 = 筛选进度`。勾表示本轮游标结束，不代表整个DB已全部展示。
- List从非零索引起读，显示“索引100–234 · 135项”；总长度另可查看，不称已加载所有List元素。
- Stream/TimeSeries有界范围的“结束”只表示提交范围已结束；不能与整个Key历史消息/样本数混用。
- 达本地缓存/扫描预算时显示醒目的“部分”与缩小范围入口；完整数值可展开查看。不能为了简洁把限制状态画成绿色完成。
- 大值预览可显示“部分64KiB”，同时通过名称/详情给出精确 `65536/131073字节`。完整大小、索引、分数是数据属性，仍保留可查路径。

## 交互与布局约束

1. 状态通过图形、按下态、短数字共同表达；颜色不是唯一信号。每个图标按钮都保留准确的title、aria-label和可见焦点。
2. 正常操作的图标优先复用现有Icon；时钟、暂停、成功和警告按同一风格补齐，不新装整套图标依赖。
3. 菜单可用键盘打开/关闭；提示兼顾悬停与键盘聚焦。常用操作不藏到“更多”里。
4. 无障碍状态播报覆盖用户启停、复制结果和真实错误；避免每5秒反复播报相同的“等待下一轮”。
5. 464px侧栏正常状态最多一条紧凑控制带；需要编辑范围/查找时在正常文档流展开，关闭后恢复高度。表格和预览保持各自滚动。
6. 保留具体错误及必要下一步，不把所有失败原因藏进提示框；同一错误在同一可见区域只呈现一次。
7. 当前DB、所选Key、数据类型至少各有一处可见上下文；聚焦详情隐藏目录时也不能丢失DB身份。

“对比当前”是按源码组织的简化示意，不是日常DSH实时截图。HTML内嵌完整Phosphor许可，无外部资源或数据接口。
