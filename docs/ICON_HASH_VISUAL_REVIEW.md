## 怎么选

图标、颜色、布局独立。主模型建议先试 **图标 1 + 蓝/绿/橙 + 布局 A**；若偏好双色和更明显的自绘特征，可比较图标 3。

| 维度 | 选项 | 比较重点 |
|---|---|---|
| 图标 1 | Tabler 实心 | 小尺寸填充面积更大，DB / 文件夹 / 钥匙容易辨认 |
| 图标 2 | Phosphor 双色 | 外轮廓与较深底色、圆形 Key |
| 图标 3 | 本项目自绘双色 | 圆柱 DB、打开的目录、圆环钥匙，细节与另外三组不同 |
| 图标 4 | Tabler 描边 | 更轻但颜色鲜明，适合不喜欢实心图形的情况 |
| 配色 | 蓝/绿/橙；紫/青/玫红；青/紫/橘 | 三套都不使用红 DB、黄目录，浅色模式另用较深的语义色 |
| Hash A | 上方表格 + 下方字段和值上下分区 | 最接近截图；固定区域各自滚动，不是遮挡表格的底部弹窗 |
| Hash B | 上方表格 + 下方字段和值左右并排 | 宽面板对照两段内容，窄栏退为 A 式上下分区 |
| Hash C | 数据区左侧表格 + 右侧字段和值 | 保留更高表格，窄栏也退为上下分区 |

回复示例：“图标 1，蓝绿橙，布局 A”。此处示例不代表用户已作选择。

## 样例可操作内容

- 同屏比较四组图标各自的 16 / 20 / 24px、DB / 目录 / Key 和选中树行。
- 选择图标和配色，下方完整 DB → 目录 → Key 导航同步更新；目录可折叠，Key 可本地筛选。
- 点击 Hash 不同字段；字段和值两个预览同时更新，Text / JSON / Hex / Base64 格式各自独立。包含空字符串、中文、多行文本、二进制等合成内容。
- 搜索已加载字段；上下键选行；局部表格与两个预览滚动。没有反复“继续扫描”按钮，加载计数来自固定演示集合。
- 试宽面板、460px 窄栏、深浅主题和表格比例。底部箭头切换 A/B/C；输入、表格、预览操作中的方向键不会误切布局。
- 样例直接呈现精简提示后的主界面；完整的 19 场景/34 正文 key 处理决定另在审查文档中，不把一大篇审查结论塞到真实操作区。

这些是一次性演示代码，不能直接混入正式数据层。正式采用后复用 `useCollectionScan`、字节身份、Host DTO 和 `BytePreview`，不迁入模拟加载或模拟数据。
