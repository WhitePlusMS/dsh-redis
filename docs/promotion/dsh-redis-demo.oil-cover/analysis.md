# 封面内容与证据

执行方式为 oil-cover Agent 自主模式，通过内置 imagegen 整图生成，不使用外部服务Key。当前没有头像配置，所有封面保持无人物。

- 主主题：在DSH工作区查看Redis。
- 主产品：DSH Redis社区只读插件。
- 承载界面：DeepSeek Harness Web；不暗示官方合作。
- 辅助品牌：无。不把Redis服务或DSH的其他界面品牌扩展成联合广告。
- 一眼主语：在DSH中定位Key后，选行就能看到字段与值。
- 主证据：原生Hash工作区中选中行及字段/JSON值预览，占重构屏幕内容约65%。
- 辅助证据：青色DB、紫色目录、橘色Key的导航，约20%；少量只读工具/产品名称，约15%。
- 可牺牲信息：长Key列表、完整JSON大数组、工具细字、时间、地址细节、其他DB、工作区历史和完整应用外框。

证据帧采用现有[Hash截图](../../screenshots/hash-workbench-dark.jpg)，因为选中字段、表格和值预览在同一个画面，能够清楚表达本产品的查看方式。图中只有隔离测试数据。副本为同目录的dsh-redis-demo.jpg及frames/hash-workbench-dark.jpg，像素内容不改动。没有为了封面连接用户Redis或重新拍摄业务数据。

产品图标来自项目根目录的[icon.svg](../../../icon.svg)，在frames内保留SVG副本，并只把该矢量原样栅格化为640×640 PNG供图生图参考；不修改项目图标形状与配色。

封面主标题锁定为“在 DSH 里 / 查看 Redis”，仅按画幅断行。它直接说明当前用途，不使用效率、性能、市场或自动修复承诺。副标题为“六种类型 · 只读查看”，依据当前六类型范围，不把未来写入当作卖点。

生成图属于从真实素材提炼的推广视觉，可能重排与重绘局部界面，不是原生截图、模型对话记录或新的运行验收证据。README继续使用原始Hash/Stream截图。
