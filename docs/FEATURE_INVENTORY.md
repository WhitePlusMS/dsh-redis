另按查看能力统计：**6 种基础数据类型 + 6 种专用查看方式、6 种字节显示格式、3 类诊断快照**。专用查看方式不等于六种独立 Redis TYPE：Bitmap、HyperLogLog 解释 String，GEO 解释 ZSet；RedisJSON、TimeSeries、Bloom 需要服务器实际提供对应模块及命令。

日常使用顺序：

```text
DSH 右侧栏 → Redis
  ├─ 连接配置 → 选择已有资料 / 新建资料 → 测试连接 → 连接
  ├─ 左侧 DB → 自动加载 Key → 目录或筛选 → 选择 Key
  │    └─ 右侧数据表 / 值预览 → 选择一行 → 同屏查看详情
  └─ 底部诊断入口 → 客户端连接快照 / 慢日志快照 / 服务器概览
```

**连接 Redis 与查看“客户端连接快照”是前后两步。** 连接窗口填写 Redis 服务器地址；连接成功后，快照展示这台服务器当时有哪些客户端连接。打开快照不需要再填写另一套地址。这里的“客户端”是连接 Redis 的程序或服务。

## 3. B、C：连接 Redis 与管理连接资料（15 项）

### 3.1 连接窗口里有哪些区域

从 Redis 未连接入口，或左上角连接地址、齿轮打开“连接配置”。宽窗口左侧是“我的连接”，右侧是服务器、认证和 TLS；URI 填写入口位于连接编辑区，资料导入/导出折叠区位于两栏下方。窄窗口改为上下排列。

| 区域 | 当前包含的信息 | 用户可以完成什么 |
|---|---|---|
| 我的连接 | 已保存连接、连接名称、分组 | 选择、新建、保存、更新、删除、刷新资料列表 |
| 服务器 | 地址、端口 | 指定要连接的 Redis 实例 |
| 认证 | 用户名、密码 | 使用默认用户或指定 ACL 用户认证 |
| TLS | 启用 TLS、可选 CA PEM | 使用加密连接和受信证书 |
| 从 Redis URI 填写 | URI 输入、“填写草稿” | 将连接字符串拆成表单内容 |
| 导入/导出连接资料 | 导出、文件选择、导入预览 | 搬移本插件的连接资料 |
| 连接操作 | 测试连接、连接；已连接时断开 | 检查是否可达，再建立或释放实际连接 |

### 3.2 字段逐项说明

| 字段 | 是否必填 / 默认值 | 当前含义与保存方式 |
|---|---|---|
| 已保存连接 | 默认“新建连接” | 下拉列出已保存资料，按分组显示；选择后填入表单，不自动连接。 |
| 连接名称 | 保存资料时必填；新建默认为空 | 最多 80 字符；用于自己识别这套连接。直接连接不要求先保存名称。 |
| 分组 | 可选；默认为空 | 最多 80 字符；空值归入“未分组”。同组同名的资料需要调整后保存。 |
| 地址 | 必填；`127.0.0.1` | Redis 主机名或 IP，最多 253 字符。 |
| 端口 | 必填；`6379` | 整数，范围 1–65535。 |
| 用户名 | 可选；空 | 最多 256 字符；默认用户可留空。连接资料可以保存用户名。 |
| 密码 | 可选；空 | 使用密码输入框，仅供当次连接/测试；**不保存到连接资料**。连接成功或关闭窗口后清空。 |
| 启用 TLS | 默认关闭 | 启用加密连接；连接资料保存 TLS 开关。 |
| CA 证书 PEM | TLS 启用时显示，可选 | 留空使用默认信任库；始终验证证书与主机名。本地保存资料可包含填写的 CA，导出文件不包含它。 |

连接窗口没有独立的 DB 编号输入框；实际连接从 DB 0 开始，连接后在左侧选择目标 DB。

### 3.4 C：连接资料能力（7 项）

| 编号 | 已实现功能 | 操作结果 |
|---|---|---|
| C01 | 选择已有连接 / 新建连接 | 选择资料填入已存设置；选择“新建连接”回到默认连接表单，可填写名称和分组。两者都不自动连接。 |
| C02 | 保存及更新配置 | 新建时“保存配置”，选中已有资料时“更新配置”；保存名称、分组、地址、端口、用户名、TLS/CA，不保存密码。最多 50 条。 |
| C03 | 删除连接资料 | 删除选中的本地资料；与删除 Redis Key 或业务数据无关。 |
| C04 | 刷新连接资料列表 | 刷新图标重新读取已保存资料；资料仍存在时保留当前选择。 |
| C05 | Redis URI 填写草稿 | 支持 `redis://`、`rediss://`、编码用户名/密码、主机、端口及数字 DB 路径；填写成功清空 URI 原文。只更新草稿，仍需手动连接和选 DB。 |
| C06 | 导出连接资料 | 下载 `dsh-redis-connections.json`，导出已经保存的名称、分组、地址、端口、用户名及 TLS 开关；不带密码、CA 或运行中连接身份。 |
| C07 | 导入预览与冲突处理 | 选择本插件格式的 JSON，先预览，逐条勾选、改名或改分组；同组同名冲突需处理。确认后新增所选资料，不覆盖原资料，也不自动连接。 |

URI 默认端口为 6379、默认 DB 为 0；当前不接受查询参数或片段。URI 中的 DB 只是浏览草稿，连接后仍需实际选择该 DB。

导入文件最多 256 KiB，导入后资料总数最多 50 条。预览可编辑名称和分组，地址等由文件提供；需要修改服务器设置时，在导入后选择该资料修改。导入的 TLS 资料不带 CA，需要自行补填。连接资料导入/导出不包含 Redis 数据。

### 3.5 第一次连接和复用连接的操作步骤

**第一次连接：**

1. 打开“连接配置”，选择“新建连接”。
2. 填写地址、端口；按需要填写用户名、密码和 TLS/CA。
3. 如需下次复用，填写连接名称、分组，点“保存配置”。密码不随资料保存；当前保存还会清空当次密码草稿，保存后需重新填写，待修问题见操作审查 P1-01。
4. 点“测试连接”，查看原按钮上的通过/失败状态；失败时按错误调整设置。
5. 点“连接”，成功后窗口关闭，左侧加载 DB 0 的 Key。
6. 点击实际需要的 DB，再选择目录和 Key。
7. 在右侧查看值；集合数据点选一行，同屏显示该行详情。

**下次复用：**打开连接配置 → 选择已保存资料 → 按需要重新填写密码 → 测试/连接。切换到其他服务器前，先断开当前连接。

## 4. D：DB 与 Key 导航（8 项）

| 编号 | 已实现功能 | 入口、操作及结果 |
|---|---|---|
| D01 | DB 目录与数量快照 | 左侧显示 DB 及数量；读取 DB 元信息受限时显示未知，不把未知当作 0。 |
| D02 | 切换 DB / 打开指定 DB | 点击 DB 选择数据库并加载目录；DB 数量未知时，可在筛选区域输入指定 DB 编号。 |
| D03 | 当前 DB 自动分批加载 | 选中 DB 后连续分批 SCAN；显示 DB 总数、已加载数量和真实进度，支持取消/刷新，无须反复点“继续扫描”。 |
| D04 | Key MATCH 筛选 | 筛选图标展开匹配条件，默认 `*`；提交后按新条件扫描。可清除条件；显示已经提交的筛选标签。 |
| D05 | 树形 / 列表切换 | 同一批已加载 Key 可切换树和列表；长目录只渲染可见行。切换显示不重新读取 Redis。 |
| D06 | 命名空间目录与分隔符 | 默认按 `:` 分组，支持自定义分隔符、折叠/展开；目录优先、名称区分大小写排序，单分支前缀合并显示。 |
| D07 | 定位与键盘浏览 | 定位当前 Key；方向键、Home/End、PageUp/PageDown 浏览，Enter/Space 打开或展开节点。 |
| D08 | Key 数据、TTL 与元信息 | 选 Key 后按类型显示数据；标题显示类型和 TTL，永久 Key 显示无过期语义；元信息提供完整 Key 字节身份及该视图可用的长度/数量等信息。 |

需要这样理解数量与进度：

- **DB 总数**是服务器数量快照；**已加载 Key**是本轮已取得的结果。Redis 数据变化时，两者可能发生差异。
- 带 MATCH 时，不把 DB 总数当作“匹配结果总数”；扫描结束表示当前条件的游标到达终点。
- 目录后面的数字只统计该目录内**已经加载**的 Key；目录是本地分组，不是 Redis 中真实存在的文件夹。
- Key 目录会自动连续加载；右侧集合则在滚动到底时追加下一批，两者触发方式不同。
- 达到读取边界时明确显示“部分”，不会把截断结果写成全部完成。当前 Key 目录边界为 5000 条/2 MiB、1000 页或 60 秒；可以缩小匹配范围后刷新。

## 5. E：六种基础数据查看（6 项）

| 编号 | 类型 | 表格或主结果 | 可操作条件与选行效果 |
|---|---|---|---|
| E01 | String | 当前字节窗口的值、已读范围、字节覆盖及完整/部分状态 | 设置起始字节及窗口大小（256/4096/16384/65536，默认 65536），提交读取或下一窗口；切换显示格式。 |
| E02 | Hash | 行号、字段、值 | 上方表格、下方字段与值两个独立预览区；点击任意单元格选整行，两处各自设置格式、查找及复制。支持服务端字段 MATCH、已加载内容关键词过滤、触底追加。 |
| E03 | List | 原始下标、元素值 | 设置起始下标及批量（1/10/25/100，默认 100）；滚动追加。选行后在固定预览区看元素；重复值仍按下标区分。 |
| E04 | Set | 行号、成员 | 设置成员 MATCH；按扫描结果增量显示、触底追加。选行直接预览成员，不额外查询或人为排序。 |
| E05 | ZSet | 范围模式显示排名、成员、原始分数；扫描模式显示成员、原始分数 | 支持按排名读取分数升序范围，或按成员 MATCH 扫描。范围模式设置起始排名及批量；选行在同屏预览成员。扫描模式不伪造排名。 |
| E06 | Stream | 消息 ID、字段对数量；选消息后的字段对表格 | 设置 ID 升/降序、最小/最大 ID、批量；滚动追加。选择消息显示其首字段对，再选字段对同时更新字段和值预览；重复字段名按出现序号保留。 |

Hash、List、Set、ZSet、Stream 均采用固定表格和同屏详情区域；选行不跳页，不用覆盖表格的底部弹窗，也不因为查看某行而重新读 Redis。Hash 和 Stream 的字段、值可以使用不同格式。

Hash 顶部关键词只过滤已经加载的字段/值字节，忽略大小写；过滤期间暂停追加，清空后恢复。它与服务端字段 MATCH 是两个功能。各类型显示的集合总数与当前匹配/加载数分别表达。

List、ZSet 的起始位置是下标/排名；ZSet 范围读取不是最小、最大分数筛选。Stream ID 范围默认 `-` 到 `+`。

## 6. F：六种专用数据查看（6 项）

| 编号 | 查看方式与进入路径 | 当前显示与操作 |
|---|---|---|
| F01 | RedisJSON：实际模块类型路由进入 | 按 JSON 路径读取，默认 `$`；显示已提交路径、匹配数、序列化字节和 JSON 内容。保留匹配结果数组语义，区分 JSON `null` 与无匹配；路径类型放在元信息。 |
| F02 | Bitmap：String 选项中“按位查看” | 起始位默认 0，数量可选 8/64/256/1024/4096，默认 256；显示位偏移、位串、总位数及返回范围，支持下一窗口和返回 String。位序按最高位在前显示。 |
| F03 | HyperLogLog：String 选项中显式切换 | 显示近似基数；编码及缓存有效性放在元信息，可返回原始 String 查看。当前不提供成员枚举。读取估算不回写源 Key 的缓存。 |
| F04 | GEO：ZSet 选项中“查看坐标” | 按起始排名/批量查看成员、原始分数、经纬度，触底追加；点击成员按钮显示成员预览，原始 Base64 身份按需展开；可返回 ZSet。保留坐标量化说明。 |
| F05 | TimeSeries：实际模块类型路由进入 | 按起止 Unix 毫秒、升/降序及批量读取；表格显示原始时间戳和值，触底追加。可切换曲线并选点；总样本、首末时间及保留策略等放在元信息。 |
| F06 | Bloom：实际模块类型路由进入 | 查看容量、记录的插入次数等统计；按需展开 Text/Base64 候选项查询，给出“可能存在”或本次阴性结果；原始候选字节按需展开。 |

专用查看有以下实际差异：

- Bitmap、HyperLogLog 和 GEO 需要用户显式选择解释方式，不会仅凭底层 String/ZSet 类型自行认定含义。
- TimeSeries 曲线只使用当前已读样本，不自动补查历史。最多取读取顺序前 512 个点，再按时间升序绘制；其余样本仍在表格，界面显示未绘制数量。点击或左右/Home/End 选点可看原始时间戳和值。
- TimeSeries 的统计信息权限与范围读取分别处理；统计不可读不直接冒充没有样本。
- Bloom 的“可能存在”不是精确命中；统计中的插入记录数也不是精确唯一成员数。统计读取与候选查询的权限/错误分别处理。
- Bloom 不枚举成员；当前未提供 Cuckoo 视图、GEO 地图、离线 RDB/AOF 文件查看。

## 7. G：格式、查找与复制（5 项）

| 编号 | 已实现功能 | 操作与显示结果 |
|---|---|---|
| G01 | 六种字节显示格式 | Text、JSON、Hex、Base64、Base64 解码为 Text、Base64 解码为 JSON。JSON 保留数字原文及重复属性，不通过重新序列化改写大整数等内容。 |
| G02 | 当前预览内查找 | 查找按钮或 Ctrl/Cmd+F 打开；仅在当前已读、当前格式的文本中区分大小写查找，显示匹配并定位。Enter/F3 下一个，Shift+Enter/Shift+F3 上一个，Escape 关闭。 |
| G03 | JSON 逐块及整体折叠 | JSON 内容可折叠单个区块、全部折叠或展开；属于本地显示操作，不重新读取 Redis。 |
| G04 | 复制当前预览 | 复制当前已读内容的当前格式文本；JSON 折叠后的省略号不会写进复制结果。成功在对应按钮短暂显示对勾，失败就地提示；字段和值分别反馈。 |
| G05 | 原始字节与覆盖说明 | Hex/Base64 可查看精确字节；空值、空成员、二进制内容有对应表达。Key 完整身份放在元信息；部分窗口保留覆盖范围，UTF-8 边界补全使用字节标记说明。 |

复制不是“导出整个 Key”：尚未加载的内容不会被静默补读。无效 UTF-8、无效 JSON、无效 Base64 或不足以解析的部分 JSON 会显示具体状态，不生成看似成功的格式化内容。

切换集合行时重置该行查找及滚动位置，保留选择的格式。关闭查找会清除高亮。

## 8. H：读取条件、刷新与取消（5 项）

| 编号 | 已实现功能 | 操作与结果 |
|---|---|---|
| H01 | 手动读取 / 刷新 | 在读取区域使用刷新箭头；沿用已经提交的条件，读取中显示忙态及取消入口。集合表格触底可继续加载。 |
| H02 | Key 自动刷新 | 页签旁图标开关，默认关闭；间隔默认 5 秒，可选 1/5/10/30 秒。按下态表示开启，不再增加“自动刷新 5 秒”等重复文字行。 |
| H03 | 取消及旧结果隔离 | 可停止等待当前读取；Key、DB、会话等发生变化后，旧请求结果不覆盖当前选择。 |
| H04 | 按需查看读取时间 | 时钟入口展开最近成功读取时间及停止原因；Key 读取、连接状态查询、诊断快照各自使用对应时间。 |
| H05 | 条件草稿与提交分离 | MATCH、范围、路径和候选查询等按需展开；输入草稿不清空当前结果，也不立即查询，提交才应用。 |

自动刷新适用于各类 Key 查看。上一轮读取完成后再等待设定间隔，不叠加定时请求。集合重新读当前查询的首个有界页，后续仍由表格触底追加；Bloom 自动刷新统计，不反复执行候选项查询。

切换 Key、DB、会话、解释方式，或界面隐藏、取消、读取失败，会停止自动刷新；重新可见或手动重连不会自行重新开启。自动刷新开关及计时器不保存。取消是停止等待，不表示已经撤销服务器正在执行的命令。

| 编号 | 功能入口 | 当前用途 |
|---|---|---|
| I01 | 底栏“客户端连接快照” | 查看当前 Redis 服务器的连接记录；主表 7 列，点地址展开 7 项详情。 |
| I02 | 底栏“慢日志快照” | 手动查看最近慢命令记录；当前主表 5 列，可选择本次读取数量。 |

### 9.1 客户端连接快照：如何操作、包含哪些信息

操作步骤：**先连接 Redis → 点底栏“客户端连接快照” → 查看主表 → 点某条地址查看详情 → 需要新状态时点刷新。**

列表面向整台 Redis 服务器。表中的 DB 是该客户端当时选中的数据库，不表示列表只筛选当前浏览 DB。

| 位置 | 字段 | 含义 |
|---|---|---|
| 主表 | ID | 客户端连接编号 |
| 主表 | 地址 | 客户端地址；点击查看该条详情 |
| 主表 | 名称 | 客户端设置的连接名 |
| 主表 | DB | 该连接当前选择的 DB |
| 主表 | 连接时长 | 连接已存在的秒数 |
| 主表 | 空闲时长 | 自上次活动起的秒数 |
| 主表 | 最后命令 | 快照中记录的最近命令名 |
| 详情 | ACL 用户 | 该连接使用的用户 |
| 详情 | 标志 | Redis 返回的客户端标志原文 |
| 详情 | 查询缓冲 | `qbuf`，单位字节 |
| 详情 | 输出内存 | `omem`，单位字节 |
| 详情 | 频道订阅 | `sub` 数量 |
| 详情 | 模式订阅 | `psub` 数量 |
| 详情 | 分片订阅 | `ssub` 数量 |

页面显示本次返回行数/总数，最多展示 200 条，截断时标明“部分”。未报告字段与空名称分别表达。点击地址只查看当前快照的本地数据，不额外访问 Redis，也不连接该地址。

### 9.2 慢日志快照：当前可见内容

| 控件 / 列 | 当前含义 |
|---|---|
| 读取数量 | 1/10/25/50/100，默认 10；调整后点刷新才按新数量读取 |
| ID | 慢日志记录编号 |

参数正文与客户端地址/名称不展示。没有清空慢日志、重置记录或设置慢日志阈值的操作。

## 10. J：会话隔离与浏览恢复（4 项）

| 编号 | 已实现功能 | 实际保存及恢复范围 |
|---|---|---|
| J01 | 配置共用、连接与浏览状态按会话隔离 | 同一 DSH profile 内连接资料共用；每个会话分别持有连接和浏览选择，切换会话不自动新建连接。 |
| J02 | 记住所选资料、DB、MATCH 和 Key | 记录连接资料 ID、DB 编号、Key 匹配条件及原始 Key 身份，恢复选择时不恢复旧值或旧游标。 |
| J03 | 记住部分显示偏好 | 保存 String/Hash/List/Set/ZSet/Stream/GEO/RedisJSON 的内容显示格式，以及已提交的 String 字节窗口。Hash/Stream 独立字段格式属于当前视图本地状态。 |
| J04 | 显式恢复读取与失败重试 | 恢复选择不自动连接或 SELECT；需要时先连接和选择 DB，再点“读取已选 Key”。浏览状态加载/保存失败时提供重试。 |

连接资料保存到当前 DSH profile 的本地文件；浏览状态只在 Host 会话生命周期内保存在内存中，不承诺退出 Host 后继续保留。密码、读取结果、扫描游标及自动刷新开关不属于浏览恢复内容。

重新连接从 DB 0 开始；记住 DB 号不表示已经切到该 DB。已有连接的当前 DB 目录可以自动加载，恢复 Key 值仍需显式读取。

## 11. 当前范围与尚未提供的能力

当前产品定位是个人使用的只读 Redis 查看器。以下能力没有算进上述 56 条：

| 方向 | 当前边界 |
|---|---|
| Redis 数据写入 | 没有新增、改值、删除、重命名 Key、设置 TTL、写入集合、清库功能 |
| 任意命令 | 没有可执行任意 Redis 命令的控制台 |
| 连接拓扑 | 当前为单机直连及 TLS，没有 Sentinel、Cluster 或内置 SSH 隧道 |
| 数据备份与文件 | 没有 RDB/AOF 离线打开、整库数据导入/导出；连接资料 JSON 只搬移连接设置 |
| 管理操作 | 没有踢客户端、修改 Redis 配置、清空慢日志、修改 ACL |
| 持续监控 | 三个诊断入口都是快照，没有历史趋势库、持续日志订阅或告警 |
| 其他专用视图 | 没有 Cuckoo 专用查看、GEO 地图或 HyperLogLog/Bloom 成员枚举 |
| 团队能力 | 没有团队共享、成员权限配置或集中审计 |
| 已发现显示缺口 | 慢日志的本机日期及参数字节摘要等被当前样式隐藏，见 9.2 |

这里仅描述当前实现边界，不把这些条目自动当作下一轮开发任务。扩展类型是否可用，还取决于目标服务器的模块与读取权限；失败、Key 过期、类型变化、空结果和部分结果保留各自状态。
