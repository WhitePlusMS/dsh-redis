## 连接窗口与完整操作

宽窗口左侧“我的连接”，右侧服务器、认证、TLS；窄窗口上下排列。实际连接身份与编辑草稿分开。

| 信息 | 默认 / 填写方式 | 保存及操作含义 |
|---|---|---|
| 已保存连接 | 新建连接 | 选择资料才填表；刷新列表不覆盖草稿，不自动联网 |
| 连接名称 | 空，保存时必填，最多80字符 | 同组内名称唯一；直接连接不必先保存 |
| 分组 | 折叠内填写，可空，最多80字符 | 空为未分组；可按分组选择资料 |
| 地址 | 127.0.0.1，必填，最多253字符 | 单机Redis主机名/IP |
| 端口 | 6379，1–65535 | 整数端口 |
| 用户名 | 空，可选，最多256字符 | 默认用户可留空；支持ACL用户 |
| 密码 | 空，可选，最多4096字符 | 仅本次草稿；资料不保存，成功连接/关闭后清空；保存不清空 |
| TLS | 折叠内开关，默认关 | 加密并始终验证证书及主机名 |
| CA PEM | TLS启用后可填，最多65536字符 | 空为默认信任库；本地资料可保存CA |
| 连接 | 手动点击 | 成功后关闭窗口、自动加载当前DB；没有单独测试步骤 |
| 删除资料 | 点击后显示资料名称，再确认或取消 | 仅删除本地资料，不触碰Redis Key |

首次：打开配置→填参数→需要复用则填名称并保存→连接→选择DB/Key→同屏查看。下次：选资料→按需补密码→连接。已连接可管理其他资料；切换服务器先显式断开。关闭设置不等于断开已建立连接；连接未完成时关闭会取消请求。

## DB / Key 导航

| 编号 | 功能 | 界面行为 |
|---|---|---|
| D01 | DB目录与数量 | 固定DBSIZE、INFO keyspace、CONFIG GET databases；权限不足显示未知 |
| D02 | 手动选择DB | 点击DB加载；数量未知时可输入指定DB，仍保留非零DB |
| D03 | 自动分批SCAN | 显示总数、已加载和进度；支持停止/刷新 |
| D04 | MATCH | 漏斗展开条件，默认*；提交才查询，可清除 |
| D05 | 树/平铺列表 | 缓存本地切换，长目录只渲染可见行 |
| D06 | 目录及分隔符 | 默认冒号，可按需更改；目录优先、区分大小写排序及折叠 |
| D07 | 定位和键盘 | 定位当前Key；方向/Home/End/PageUp/PageDown，Enter/Space打开节点 |
| D08 | 数据与元信息 | 类型、TTL、可用长度/数量及完整Key原始字节身份 |

DB数量是读取时的数量；目录只计已加载Key。带MATCH不把DB总量冒充匹配总量。Key扫描边界为5000条/2MiB、1000页或60秒，达到边界显示部分；缩小筛选可继续查看。目录是本地分组。

## 六种基础类型

| 编号 | 类型 | 表格及同屏详情 | 查询条件 |
|---|---|---|---|
| E01 | String | 字节窗口、覆盖范围、完整/部分标识 | 起始字节；256/4096/16384/65536字节，默认65536；下一窗口 |
| E02 | Hash | 行号/字段/值表格，下方字段和值各自预览 | 服务端字段MATCH；本地关键词过滤已加载字节；触底追加 |
| E03 | List | 原始下标、元素；选行值预览 | 起始下标；1/10/25/100条，默认100；触底追加 |
| E04 | Set | 行号、成员；选行成员预览 | 成员MATCH；无序扫描，触底追加 |
| E05 | ZSet | 成员、原始分数；范围模式有排名；选行预览 | 按排名升序范围，或按成员MATCH扫描；扫描不伪造排名 |
| E06 | Stream | 消息表、字段对表、字段和值预览同屏 | ID正/倒序，默认-到+，批量1/10/25/100；触底追加 |

集合点击单元格选择整行；方向键切行；不跳页、不覆盖表格，不为预览额外读取。Stream选消息显示首字段对，重复字段按出现序号保留。Hash本地搜索忽略大小写，期间不触底续读，清空后恢复。总数与已加载/匹配数分开。

## 内容、刷新和会话

| 编号 | 功能 | 操作 |
|---|---|---|
| G01 | 四种格式 | Text、JSON、Hex、Base64；JSON保留数字及重复属性原文 |
| G02 | 查找 | 查找按钮/Ctrl或Cmd+F；Enter/F3下一处、Shift反向、Escape关闭 |
| G03 | JSON折叠 | 逐块/全部折叠或展开，本地操作 |
| G04 | 复制 | 当前预览的当前格式；该按钮短暂反馈，折叠省略号不进复制 |
| G05 | 原始字节与覆盖 | Hex/Base64精确显示；UTF-8边界补全、空值及部分结果明确表达 |
| H01 | 手动刷新 | 沿用已提交条件；同一查询保留画面直到新批次完成 |
| H02 | 自动刷新 | 图标开关+间隔；默认关闭及5秒，可选1/5/10/30秒 |
| H03 | 取消和迟到隔离 | 取消等待；Key/DB/会话变化后旧回复不覆盖新选择 |
| H04 | 最近读取 | 时钟按需展开成功时间和停止原因；连接状态时间独立 |
| H05 | 条件草稿 | 范围/MATCH按需展开，点应用才读取；刷新不提交草稿 |
| J01 | 会话隔离 | 资料在profile共用；网络连接、DB及请求按会话隔离 |
| J03 | 挂载期间格式 | 六视图格式在当前挂载会话内保留；不持久化DB/Key/搜索/窗口 |

自动刷新上一轮完成后再等待，不叠加定时读取。集合重新读已加载批次数，在原缓存/页数边界内完成后替换，并非事务快照。相同内容的选行、查找、折叠及局部滚动不因加载阶段卸载；内容实际变化会重算格式和匹配。原选行未包含在新批次时提示重选，不误报删除。

切换Key/DB/会话、隐藏、取消或失败停止自动刷新；重新可见/重连不自行开启。切换集合行重置该行查找和滚动，格式保留。复制、格式化、查找、折叠不访问Redis，也不补读未加载内容。

## 已退出的功能

删除B04独立测试、C05–C07 URI/资料导入导出、六种专用视图、三个诊断快照、TimeSeries曲线、显式Base64解码、Host浏览恢复及对应RPC/DTO/命令。

普通String内JSON仍可格式化；GEO底层ZSet、Bitmap/HLL底层String原始数据仍可看。RedisJSON、TimeSeries、Bloom等模块Key显示不支持。不直接打开RDB/AOF文件，不提供写Key、命令控制台或连接诊断；TLS、手动非零DB和会话隔离保留。
