## 共同行为

- 以当前对话明确连接的 Redis 和 DB 为范围，普通查询不擅自切换连接、跨库或借用其他会话。目标不明或候选不唯一时列出可核验候选并请用户补充，不猜业务含义。
- 只读取解决问题所需的数据；单次和连续调用都受数量、字节、时间与取消预算限制。MATCH 是 Key 名字符模式，不是业务语义或值搜索；未完成扫描、读取失败、截断和并发变化必须如实说明。SCAN 结束也不是原子快照。
- 业务数据进入 DSH 对话和模型前，明确连接、目标和发送范围；验收默认使用隔离的合成 Redis 数据。密钥、口令、私钥和带凭据的 URI 不进入模型参数、日志或报告。
- 所有业务读取复用现有 Host/reader、会话身份及只读命令门禁。写入数据、任意命令和脚本不因自然语言请求而开放。新增命令和参数先核对目标版本的官方契约。
- 每个 AI 场景使用真实 DSH 和用户的可用模型验证：记录用户问题、实际插件工具调用、目标、结果、范围、失败及构建；脚本模型或合成浏览器不能代替真实对话。涉及界面时额外保留真实 DSH 界面结果。
- 固定版本、权限、取消、迟到结果和跨会话隔离均需按实际改动验证；TypeScript 错误优先处理。真实数据与外部服务不作为默认测试夹具，不清理或停止不属于本任务的服务。

**工作范围：** 先复用类型、TTL 和长度；针对明确对象补充经验证的内存读取、两个 Key 或两次有限快照的比较。按适用权限分别提供服务器/DB 概况、有界慢日志、客户端列表和 Stream 消费组状态；可以把用户选择的已读诊断结果保存为本地报告。能力未知、不支持、无权限、空结果与失败分别表达。
