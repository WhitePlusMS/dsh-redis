## 范围和拆分原则

- 个人使用、严格只读、单机直连/TLS、配置在 profile 内共用而浏览状态按会话分离。
- P0 覆盖 String、Hash、List、Set、ZSet、Stream、RedisJSON、Bitmap、GEO、HyperLogLog、TimeSeries、Bloom 的查看能力。
- 基础显示是 Text、JSON、Hex、Binary/Base64 与显式 Base64 解码；压缩/其他序列化格式留在后续候选。
- 每票交付一条可展示或验证的用户流程，包含所需严格契约、Host 行为、UI 和有意义的验证；不按“写 DTO / 写后端 / 写前端”水平拆开。
- 字节身份、只读 Host、目标代次、错误和预算从第一条相关功能落地，并由之后类型票沿用；不推迟到最后补基础。
- 保持独立项目，不为更新参考源码进行无关重构，不修改 Git Graph 或 Database 原项目。包、侧栏、RPC 和样式使用独立身份。
- 任务正文不锁定具体代码文件路径或代码片段；实现位置由当前模块边界确定。
- 编号是依赖顺序，不是必须全串行。P0 优先调度，P1 的技术依赖不人为增加“全部 P0 完成”边。

## 共同验收约束

每张涉及 Redis 数据的票都必须验证只读命令、二进制身份、旧结果隔离、权限/消失/类型变化、取消/超时和实际结果边界；不能仅增加界面或只通过模拟就算完成。每张代码票执行适当的严格类型检查和专项验证，并记录真实结果与未验证范围。更新说明记录改动原因、影响和验证。

输出截断不等于驱动接收内存受限；扫描条数提示不等于固定结果大小。TLS 验证、HLL 缓存、TimeSeries 边界和 Bloom 概率语义按实施方案处理。测试只能使用独占测试数据；本次没有执行这些测试。

1. **01｜P0｜在独立 DSH 侧栏看到插件状态**

    **Blocked by:** None (can start immediately)

    **What it delivers:** 用户打开独立 Redis 页签，能看到连接空态和真实 Host 状态；页签、协议、Host 调用和安装包加载形成第一条完整链路。

    **历史验收基线：** 下列摘要与正式 01 中已勾选项对应当时的 rc.2 验收，不代表新的稳定正式目标已满足。当前继续用户随后指定的rc.2；以后另行迁移稳定版时，再核实目标、升级和接入复验，不将历史迁移要求作为本轮等待条件。29票编号、状态与依赖不变。

    **历史验收摘要：** 当时核对用户指定的 DSH `0.2.0-rc.2`、实际入口/Node/profile 与配套 SDK，只适配该版 API；本机同版无需重装。取得对应宿主及当时最新 Git Graph、DSH Database 独立副本，记录来源/tag/SHA/日期/许可，在新项目裁剪改造必要骨架和读取分支。原生侧栏调用 Host 成功，加载失败可重试，卸载/重载不重复注册；类型、最小契约回归、构建与产物入口检查通过，不依赖 Git Graph 业务代码。现行后续版本条件见本文件共同约束和发布票 21。

2. **02｜P0｜手动测试、连接和断开单机 Redis**

    **Blocked by:** 01 在独立 DSH 侧栏看到插件状态

    **What it delivers:** 用户输入单机地址、账号和密码，可以测试连接、手动连接、查看状态并断开；此阶段凭据只在 Host 内存中。

    **验收摘要：** 测试连接在成功和失败出口都释放临时资源；断开后不自动重连。 认证失败、不可达、连接错误分别显示，公开响应和日志不泄露凭据。 连接有稳定身份与代次，Host 不提供任意命令或数据写入口；完成受控回归与适用实连。

3. **03｜P0｜通过验证服务器身份的 TLS 连接**

    **Blocked by:** 02 手动测试、连接和断开单机 Redis

    **What it delivers:** 用户启用 TLS、配置必要 CA 后连接 Redis，能够分辨证书、主机名或连接失败。

    **验收摘要：** 验证正确 CA、错误 CA、主机名不匹配及正常可信证书链。 不提供默认跳过验证路径，不加入 mTLS 客户端私钥功能。 TLS 失败和断开均清理连接，表单、严格契约、Host 与实际 TLS 验证一致。

4. **04｜P0｜保存和重新选择个人连接配置**

    **Blocked by:** 03 通过验证服务器身份的 TLS 连接

    **What it delivers:** 用户保存普通和 TLS 连接资料，重开插件后可重新选择并手动连接；秘密不以明文持久化。

    **验收摘要：** 配置归当前 DSH profile，插件重开不会自动联网，配置不写入被查看的业务仓库。 密码默认只在 Host 内存；若提供记住密码，必须用核实的平台保护机制，失败不退回明文。 公开配置不回传密码；保存、更新、删除和重开流程及失败分支可核验。

5. **05｜P0｜选择 DB 并增量检索 Key**

    **Blocked by:** 02 手动测试、连接和断开单机 Redis

    **What it delivers:** 用户选择 DB、输入匹配模式、继续加载并刷新 Key 列表，能区分已加载数量和扫描是否结束。

    **验收摘要：** 使用增量扫描；空页但游标未结束时仍可继续，重复 Key 按原始字节去重。 DB 客户端相互隔离；切换 DB、搜索或连接后旧游标和旧结果不能混入。 二进制 Key 可从列表定位；DB 发现权限不足不阻止显式 DB 浏览；不默认全量扫描。

6. **06｜P0｜查看 String 的元信息和四种基础格式**

    **Blocked by:** 05 选择 DB 并增量检索 Key

    **What it delivers:** 用户从列表选择 String，查看类型、TTL、长度、时间与字节区间，并切换 Text、JSON、Hex、Binary/Base64 或显式 Base64 解码。

    **验收摘要：** 按字节区间读取大 String，不先全量读取再声称有界；完整、分段、截断和错误状态分开。 空值、非法 UTF-8、字符跨段、JSON 大整数和解码失败不改变原始字节。 建立后续查看器复用的目标校验、预览预算和错误结果；UI 无保存/删除，Host 只接受结构化读取。

7. **07｜P0｜分页查看 Hash 字段和值**

    **Blocked by:** 06 查看 String 的元信息和四种基础格式

    **What it delivers:** 用户选择 Hash 后可以浏览字段和值、继续读取并打开单元格字节预览；同时形成后续集合查看器可复用的表格。

    **验收摘要：** 字段和值保留字节身份，分页去重与当前页筛选范围清楚。 扫描条数提示不能当作字节上限；巨大字段/值有明确截断、拒绝或降级行为及实际接收边界记录。 超时、无权限、Key 消失/类型变化和刷新分别覆盖，表格复用不引入写操作。

8. **08｜P0｜按原始索引查看 List**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户浏览 List 的连续区间、原始索引和元素内容，能继续读取和刷新。

    **验收摘要：** 索引从零开始并保留，重复值不合并成一个元素。 边界、空页、巨大元素与二进制元素有正确预览及预算。 并发插入/删除时不宣称快照一致；接口、表格与回归覆盖区间语义。

9. **09｜P0｜增量查看 Set 成员**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户扫描 Set 成员，继续读取并查看成员的文本和字节内容。

    **验收摘要：** 成员按原始字节处理和去重；无序扫描不伪装成全局排序。 游标、空页、超大成员和刷新状态正确。 受限账号、Key 消失/类型变化及只读命令边界有回归。

10. **10｜P0｜查看 ZSet 成员与分数**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户查看 ZSet 的成员、分数和后续区间，明确区分有序读取与游标扫描。

    **验收摘要：** 成员身份无损，分数原文保留；分页方式和排序范围明确。 大成员、边界分数、空结果及变化中的集合有可辨认状态。 读取、协议、表格与验证共同交付，并保留后续 GEO 视图的原始 ZSet 入口。

11. **11｜P0｜按消息 ID 查看 Stream**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户按消息 ID 范围查看 Stream，继续读取消息及其原始字段对。

    **验收摘要：** 分页边界不重复/漏项，重复字段名不因转换成普通对象丢失。 巨大消息、二进制字段、消失/变化的 Key 与权限失败有明确处理。 查看不创建/推进消费组、不增加 Pending、不 ACK；有实际命令与状态证据。

12. **12｜P0｜查看 RedisJSON 根值和指定路径**

    **Blocked by:** 06 查看 String 的元信息和四种基础格式

    **What it delivers:** 用户查看真正的 RedisJSON 内容或缩小到指定路径，明确区别于普通 String 的 JSON 格式化。

    **验收摘要：** 命令缺失、无权限、路径不存在、类型不符分别显示。 单个巨大节点不伪装成通用分页；可拒绝/缩小路径并说明实际接收和外发预算。 不使用不可靠的 Number 转换重写大整数，全部读取无写回；适用扩展版本有实测记录。

13. **13｜P0｜按位偏移查看 Bitmap**

    **Blocked by:** 06 查看 String 的元信息和四种基础格式

    **What it delivers:** 用户从 String 进入 Bitmap 视图，指定偏移后查看有限位窗口和总长度。

    **验收摘要：** 位顺序、起止边界和字节转换正确；不会展开整个巨大值。 只使用固定的只读位读取方式，不提供位写入口或可混入写子命令的参数通道。 普通二进制 String 不被自动确认为 Bitmap，目标变化和越界状态有回归。

14. **14｜P0｜从 ZSet 切换查看 GEO 坐标**

    **What it delivers:** 用户保留原始 ZSet 视图，并可选择 GEO 查看成员经纬度。

    **验收摘要：** 不把一次坐标探测成功当作业务类型证明，普通 ZSet 仍可原样查看。 有界读取成员坐标，二进制成员身份不由展示文本重建。 空/缺失坐标、不可用命令和权限失败可辨认；不要求地图或外网瓦片。

15. **15｜P0｜只读查看 HyperLogLog 估算数量**

    **Blocked by:** 06 查看 String 的元信息和四种基础格式

    **What it delivers:** 用户查看 HLL 识别信息和估算数量，读取不改写源 Key 的基数缓存。

    **验收摘要：** 采用已核对官方语义的临时合并计数路径，不静默退回会改源缓存的单输入路径。 稀疏/稠密、失效缓存、缺失 Key、伪签名、ACL 和读取前后原字节/绝对过期时刻分别验证。 识别失败保留字节查看；估算不冒充精确值或原始成员枚举；静态核对不能代替实连。

    **What it delivers:** 用户展开详情、搜索当前内容、复制和折叠 JSON，保留同一份选择与预览状态。

    **验收摘要：** 搜索仅作用于已读内容，不伪装为服务端全量搜索。 进入/退出聚焦、返回定位、主题和快捷键状态一致。 格式化不重写原始值，大内容处理继续遵守已有预算。

24. **24｜P1｜整理、导入和导出连接资料**

    **Blocked by:** 04 保存和重新选择个人连接配置

    **What it delivers:** 用户重命名/分组连接、录入 URI，预览导入配置并导出非敏感资料。

    **验收摘要：** 导出无密码等秘密，URI 输入不进入日志或错误回显。 导入冲突有明确处理，保存后不自动连接。 导入/导出/分组与重开后的实际选择流程通过，保持配置与秘密分离。

25. **25｜P1｜查看 Redis 服务器概览快照**

    **Blocked by:** 06 查看 String 的元信息和四种基础格式

    **What it delivers:** 用户打开概览查看 INFO 中的选定服务器、内存、连接和计数信息，并手动刷新。

    **验收摘要：** 缺字段、权限不足、计数/单位和采集时间明确。 只调用固定只读诊断入口，结果有预算，不修改服务器配置。 读取、解析、卡片展示和真实版本样本验证形成闭环；持续图表不塞入本票。

26. **26｜P1｜查看有界的慢日志快照**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户读取有限条慢日志，查看耗时、时间和受限命令参数摘要。

    **验收摘要：** 不增加慢日志清空或重置操作；敏感参数和巨大正文受控展示。 微秒等单位正确，版本差异、无权限、空结果和超限状态明确。 Host 读取、解析、表格和适用实连验证共同交付。

27. **27｜P1｜查看有界的客户端连接快照**

    **Blocked by:** 07 分页查看 Hash 字段和值

    **What it delivers:** 用户查看当前 Redis 客户端列表中的选定字段和统计，明确完整或截断状态。

    **验收摘要：** 字段缺失/新增和不同版本响应不导致误读，无权限与空结果区分。 不增加踢连接、暂停或其他管理写动作，地址等信息不落常规日志。 大列表的实际返回与展示边界记录清楚，表格和刷新行为验证通过。

28. **28｜P1｜受控自动刷新当前选中 Key**

    **Blocked by:** 19 取消读取并从超时或断线中恢复

    **What it delivers:** 用户手动开启当前 Key 的自动刷新，能看到时间与失败状态，隐藏或关闭面板后停止。

    **验收摘要：** 定时读取不叠加无界请求，不跟随旧会话/旧 DB/旧 Key 继续刷新。 可见性、取消和连接状态共同控制刷新，恢复可见时不自动新建连接。 验证最小间隔、慢请求、断线、退出与资源释放，不引入持续订阅。

29. **29｜P1｜把已读取的 TimeSeries 样本显示为曲线**

    **Blocked by:** 16 按时间范围查看 TimeSeries 样本

    **What it delivers:** 用户在样本表格与曲线之间切换，查看选定时间范围中的实际已读数据。

    **验收摘要：** 曲线保留时间精度与时区说明，不把局部样本画成完整范围。 大量样本有可说明的显示预算/抽样规则，不悄悄删除异常值。 空范围、重复刷新、布局和数据点提示可验证；不额外查询无限历史。
