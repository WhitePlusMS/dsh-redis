## 真实模型调用和界面结果

1. 收起 Redis 侧栏后，模型调用 `redis_viewer_show` 返回 `applied`，界面实际打开面板。
2. 模型定位合成 Key `fixture:set`，返回 `applied`。
3. 模型使用二进制身份 `AP8C` 定位 Set 成员，返回 `applied`；随后不带参数读取，结果为同一字节身份。
4. 模型定位不存在的合成成员 `synthetic-missing`，返回 `selection-missing`。
5. 界面 MATCH 条件为 `synthetic-set-first` 时，模型定位筛选外的 `synthetic-set-second` 返回 `applied`；界面选中该成员，已加载数量仍为 1。
