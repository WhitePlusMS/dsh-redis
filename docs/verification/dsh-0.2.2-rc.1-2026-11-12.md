# DSH 0.2.2-rc.1 安装与工具验证

日期：2026-11-12。平台：Windows，Node.js 24.22.1，pnpm 11.22.0，DSH Web 0.2.2-rc.1，Cordis 4.1.0。

## 执行范围与结果

- 基于 `dsh-redis` 0.1.2 源码构建，类型检查和完整打包回归通过：90 个测试文件、743 项测试。原生工具执行器、审批服务和会话投影使用与目标宿主相同的 DSH 版本。
- 在独立 DSH_HOME 和 profile 中，通过 DSH 官方插件命令安装候选包；组合配置包含 `ui-redis`。隔离安装包内 `lib` 的 128 个文件与本地构建字节一致。
- 在真实 DSH Web 的临时工作区中打开 Redis 右侧栏，连接本机隔离 Redis 8.2.6，DB 0 加载两个合成 Key；选择 String 后界面显示完整值 `before-string`。
- 在同一版本 DSH 的 Agent 管线中使用确定性模型适配器：模型侧提交写入提案、把提案交给执行工具，并接收 `written-verified` 工具结果；分别将隔离 String 与 Hash 测试值从 `old` 改为 `new`，由独立 Redis 客户端核对。该适配器是测试替身，不代表真实大模型已在本次新宿主对话中完成调用。
- 写入权限测试使用新版原生工具执行器及真实 DSH 审批服务；询问时没有应答通道会返回 unavailable，确认不会写入。其他审批模式和生产网络故障没有在本轮真实宿主中逐一验收。

本轮不连接业务 Redis，不更改用户的日常 DSH profile。临时宿主与 Redis 夹具均已停止，夹具已清理。2026-11-12 在 DSH 0.2.1-rc.5 上进行的真实 bzkj-LLM String 写入另见 `UPDATE_LOG.md`，不当作本轮 0.2.2 实测。
