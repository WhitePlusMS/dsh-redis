**Status:** ready-for-agent

**Priority:** P1

- [ ] 导入/导出/分组与重开后的实际选择流程通过，保持配置与秘密分离。
- [ ] 交付所需的严格类型契约、Host 行为和界面；完成适当类型检查与专项验证，实际证据、未验证范围及改动原因和影响记入更新说明。
