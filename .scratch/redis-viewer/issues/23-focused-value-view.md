# 23: 聚焦详情并搜索、折叠已读内容

**What to build:** 用户展开详情、搜索当前内容、复制和折叠 JSON，保留同一份选择与预览状态。

**Blocked by:** 20 在窄宽侧栏和两种主题下完成查看

**Status:** ready-for-agent

**Priority:** P1

- [ ] 搜索仅作用于已读内容，不伪装为服务端全量搜索。
