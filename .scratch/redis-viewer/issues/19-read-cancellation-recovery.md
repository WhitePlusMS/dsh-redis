# 19: 取消读取并从超时或断线中恢复

**What to build:** 用户取消慢请求或遇到断线/超时时能看到准确状态并手动恢复，其他会话的读取继续可用。

**Blocked by:** 18 按 DSH 会话恢复各自的浏览状态

**Status:** done

**Priority:** P0

- [x] 排队和并发有界，排队后派发前复查目标代次，取消与超时不伪装成功。
- [x] 取消一个请求不无条件销毁共享客户端；前端忽略结果不冒充服务器已经停止计算。
