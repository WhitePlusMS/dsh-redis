# 19: 取消读取并从超时或断线中恢复

**What to build:** 用户取消慢请求或遇到断线/超时时能看到准确状态并手动恢复，其他会话的读取继续可用。

**Blocked by:** 18 按 DSH 会话恢复各自的浏览状态

**Status:** ready-for-agent

**Priority:** P0

- [ ] 排队和并发有界，排队后派发前复查目标代次，取消与超时不伪装成功。
- [ ] 取消一个请求不无条件销毁共享客户端；前端忽略结果不冒充服务器已经停止计算。
- [ ] 断线后重连产生新代次，不自动重放旧读取队列；验证失败出口和插件退出资源清理。
- [ ] 验证本票读取的只读命令、字节身份、目标代次、权限/消失/类型变化、取消/超时和实际结果边界；输出截断不冒充驱动接收内存受限。
- [ ] 交付所需的严格类型契约、Host 行为和界面；完成适当类型检查与专项验证，实际证据、未验证范围及改动原因和影响记入更新说明。
