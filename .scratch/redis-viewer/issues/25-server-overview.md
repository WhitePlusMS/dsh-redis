# 25: 查看 Redis 服务器概览快照

**What to build:** 用户打开概览查看 INFO 中的选定服务器、内存、连接和计数信息，并手动刷新。

**Blocked by:** 06 查看 String 的元信息和四种基础格式

**Status:** ready-for-agent

**Priority:** P1

- [ ] 缺字段、权限不足、计数/单位和采集时间明确。
- [ ] 只调用固定只读诊断入口，结果有预算，不修改服务器配置。
- [ ] 读取、解析、卡片展示和真实版本样本验证形成闭环；持续图表不塞入本票。
- [ ] 验证本票读取的只读命令、字节身份、目标代次、权限/消失/类型变化、取消/超时和实际结果边界；输出截断不冒充驱动接收内存受限。
- [ ] 交付所需的严格类型契约、Host 行为和界面；完成适当类型检查与专项验证，实际证据、未验证范围及改动原因和影响记入更新说明。
